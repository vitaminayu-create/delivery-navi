# 配送ナビ(試作版)

配送スタッフがスマホで、組合員から聞かれた内容にその場で答えるためのアプリです。
技術者でなくても、`data` フォルダの中のファイルを編集するだけで、表示される内容を更新できます。

## 1. 使い方

`index.html` をダブルクリックして開くだけで動きます。ChromeやEdge、Firefoxなど、どのブラウザでも
特別な準備なしにそのまま表示されます。

## 2. フォルダの中身

```
配送ナビ/
├── index.html          … アプリ本体(触らなくてOK)
├── style.css            … 見た目(触らなくてOK)
├── app.js                … 動きの仕組み(触らなくてOK)
├── data/
│   ├── marks.js         … カタログマーク(お届け形態・供給予定・調理方法・その他・独自マーク・ポイント制・栽培基準・GMO・アレルゲン)
│   ├── procedures.js    … 手続き・利用案内の項目
│   ├── producers.js     … 地元の生産者
│   └── links.js          … 公式サイトへのリンク集
└── README.md             … このファイル
```

**情報を更新したいときは、`data` フォルダの中の4つの `.js` ファイルだけを編集してください。**
`index.html` / `style.css` / `app.js` は触らなくても情報更新はできます。

## 3. なぜ `.json` ではなく `.js` なのか

以前は `data/marks.json` のような形式でしたが、Google ChromeやMicrosoft Edgeでは、
`index.html` をダブルクリックしただけで開いた場合、セキュリティの仕組み(CORS)によって
`.json` ファイルを読み込めず、画面が真っ白になってしまう問題がありました。

そこで、データを `.js` ファイルに変え、`index.html` から `<script>` タグで直接読み込む方式に変更しました。
これにより、ダブルクリックで開いただけでもどのブラウザでも確実に表示されます。
**編集するときの書き方(中身の形)は、以前の `.json` とほぼ同じです。** 上下にある決まった書き出し・締めくくりの行(下記4章参照)だけ触らないようにすれば、それ以外の編集感覚は変わりません。

## 4. `.js` ファイルの共通ルール

どのファイルも、次のような形をしています。

```js
/*
 * 配送ナビ:○○のデータ
 * このファイルを編集して情報を更新できます。
 * 一番下の「};」は消さないでください。
 */
window.DELIVERY_NAVI_DATA = window.DELIVERY_NAVI_DATA || {};
window.DELIVERY_NAVI_DATA.marks = {
  … ここに情報が入っています …
};
```

- **編集してよいのは `{ … }` の中身だけです。** 1〜6行目(コメント・`window.DELIVERY_NAVI_DATA...` の行)と、
  一番最後の `};` は書き換えたり消したりしないでください。
- メモ帳や「メモ帳+」、VSCodeなどのテキストエディタで開いて編集できます(Wordは使わないでください。書式が壊れます)。
- `"　"`(ダブルクォーテーション)や `,`(カンマ)、`{ }` `[ ]` の対応を崩さないように注意してください。1か所崩れるだけでアプリ全体が表示されなくなります。崩れた場合は、画面上部に赤い注意メッセージが表示されます。
- 編集後は、保存してからブラウザを再読み込み(リロード)すれば反映されます。
- 自信がない場合は、編集前に元のファイルをコピーして残しておくと安全です。
- 迷ったら、似ている既存の項目をそのままコピーして、中身だけ書き換えるのが一番安全です。

## 5. data/marks.js の編集方法(カタログマーク)

1つのマークは、次のような形をしています。

```json
{
  "mark": "蔵",
  "color": "紫",
  "official": "冷蔵品",
  "memberNote": "【案・要確認】冷蔵でお届けしている商品の印です。...",
  "aliases": ["冷蔵", "くら"]
}
```

- `mark`:マークの名前
- `color`:色(検索でも使われます。色がない場合は `null`)
- `official`:**カタログの公式説明。一字一句、カタログの文言と変えずに入力してください。**
- `memberNote`:組合員への一言。**必ず文頭に「【案・要確認】」を付けてください。**(商品部などの確認が済むまでは、この表記を外さないでください)
- `aliases`:検索でヒットさせたい別名(なければ `[]`)

同じ形のかたまり(`{ ... }`)を、カンマ `,` で区切って追加すれば、マークを増やせます。

GMOのように画面の一番上に説明文を出したいカテゴリーには `intro` という項目があります。
その中の `explanation` / `note` が公式の文言、`warning` は画面での注意書きです。

「添加物」の準備中メッセージは、ファイル先頭付近の `additives` の `status` に入っています。

## 6. data/procedures.js の編集方法(手続き・利用案内)

`title`(項目名)と `summary`(説明文)を編集できます。`summary` を空にしたい場合は `null` にしてください。
「脱退」の項目だけは特別な作りになっていて、`officePhone`(事務所電話番号)と `officeHours`(受付時間)を編集できます。

## 7. data/producers.js の編集方法(地元の生産者)

現在はサンプル1件(架空のデータ)のみが入っています。画面には「サンプル(架空)」と表示されます。
実際の生産者情報に差し替える場合は、`isSample` を `false` にし、`sampleLabel` の行は削除してください。
生産者を増やしたい場合は、`items` の中に同じ形のかたまりを追加してください。

## 8. data/links.js の編集方法(外部リンク)

公式サイトのURLが変わった場合は、該当する `url` の値だけを書き換えてください。

## 9. メモ・声の記録について

- 入力された内容は、この端末のブラウザの中(localStorage)だけに保存されます。他の端末やサーバーには送られません。
- 一覧画面の「CSV書き出し」ボタンで、記録した内容をCSVファイルとしてダウンロードできます(Excelで開けます)。
- ブラウザの閲覧履歴・データを消去すると、記録も消えてしまいますのでご注意ください。
- 将来、チームで記録を集計できるように、1件ごとのデータに `syncStatus` という項目をあらかじめ持たせてあります(今回は使用しません)。
